# Contributing

Thanks for helping out.

- **Security issues:** don't open a public issue; see [SECURITY.md](SECURITY.md).
- **Bugs and ideas:** open an issue first, so we can agree on the approach before you write code.
- **Pull requests:**
  - Keep each PR to one change, with tests. CI requires 100% line and branch coverage, plus passing lint, static-analysis and secret scans.
  - Commits must be signed.
  - PRs are squash-merged.
  - Follow the repository's `AGENTS.md` for its conventions. That file applies to human and AI contributors alike.
- **Licensing:** by contributing, you agree that your contribution is licensed under the repository's license.
