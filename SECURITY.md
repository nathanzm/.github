# Security policy

## Reporting a vulnerability

**Please don't open a public issue.** Report privately through the repository's **Security** tab → **Report a vulnerability** (GitHub private vulnerability reporting).

Please include the affected version or commit, steps to reproduce, and the impact you expect.

## What to expect

- Acknowledgement within 7 days. This is a small, independently maintained project, so this is best effort.
- A fix or mitigation plan once the report is confirmed, then a published security advisory crediting you, unless you'd rather stay anonymous.

## Supported versions

Only the latest release gets security fixes.
